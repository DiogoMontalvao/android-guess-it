# Android - Guess It
Desenvolvido a partir do curso: [Developing Android Apps with Kotlin](https://www.udacity.com/course/developing-android-apps-with-kotlin--ud9012), disponibilizado pelo Google.<br><br>

Apesar de possuir uma interface simples, o projeto tem foco no aprofundamento de conceitos da arquitetura Android e os benefícios da divisão de responsabilidades dentro do app. 

##
### Foco no aprofundamento das ferramentas:

  - UI Controller;
  - ViewModel, ViewModelFactory;
  - LiveData, Events;
  - Lifecycle;
  - Navigation, Safe Args;
  - Data Binding.
